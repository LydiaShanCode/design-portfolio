## From rewards to a financial hub

Historically, the Shop App used "Shop Cash", a reward system that felt like "fun money." The goal of this North Star project was to deprecate the rewards-only model and introduce Shop Balance: a buyer-facing account that functions like a debit card, allowing users to store, spend, and earn within the Shopify ecosystem. As the sole designer on this zero-to-one initiative, I partnered with a Product Manager to define the product features and core utility.
